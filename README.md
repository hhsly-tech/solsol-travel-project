# 솔솔부부 여행프로젝트

부부 여행 일정과 준비 기록을 보관하는 개인용 정적 웹페이지입니다.
현재 첫 번째 여행은 **2026 후쿠오카 · 유후인 여행**입니다.

## 파일 구조

```text
/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── images/
```

## 실행

- `index.html`을 더블클릭해 바로 실행할 수 있습니다.
- VS Code에서는 Live Server 확장 기능으로 열어도 됩니다.
- 별도의 설치나 빌드 과정은 필요하지 않습니다.

## 여행 추가·수정

왼쪽 여행 목록의 **새 여행 만들기** 버튼으로 웹에서 여행을 생성할 수 있습니다. 시작일·종료일은 캘린더로 선택하고, 국가명은 한글 검색으로 선택합니다. 여행 카드를 클릭하면 해당 여행 페이지로 전환되고, 카드 오른쪽의 연필 버튼으로 수정·삭제할 수 있습니다.

기본 여행 데이터와 일정 데이터는 [script.js](./script.js) 상단의 `initialTripCollection`에 모아두었습니다.

- 현재 여행의 일정: 선택한 여행 객체의 `days`
- 음식 계획: `foodPlan`
- 교통 정보: `transport`
- 코드로 기본 여행을 추가하려면 `initialTripCollection`에 같은 형식의 여행 객체를 추가

여행 데이터는 Google Apps Script 웹 앱을 통해 Google Drive의 `solsol-travel-data.json`에 저장됩니다. 두 사람이 같은 GitHub Pages 링크를 열면 같은 여행 데이터를 보고 수정할 수 있습니다. 연결 방법은 [google-apps-script/README.md](./google-apps-script/README.md)를 참고하세요.

왼쪽 **여행 목록**에서 여행을 선택하면 해당 여행의 내용이 화면에 표시됩니다. 데스크톱에서는 왼쪽 고정 네비게이터로, 모바일에서는 상단 가로 목록으로 나타납니다. 새로 만든 여행은 빈 일정 페이지로 시작하며 이후 일정 데이터는 `script.js`에서 추가할 수 있습니다.

선택한 여행 화면에서는 다음 항목을 웹에서 바로 관리할 수 있습니다.

- 여행 기본 정보: 여행 이름, 여행지, 기간
- 여행 흐름: Hero 영역의 요일·지역·세부 장소
- 항공편: 추가, 수정, 삭제
- 숙소: 추가, 수정, 삭제
- 일자: 추가, 수정, 삭제
- 일자별 일정: 추가, 수정, 삭제
- 일정 시간: 5분 단위 드롭다운 선택 및 시간순 자동 정렬
- 일정 분류: FOOD, HOTEL, BUS 등 이름·아이콘 수정, 추가, 삭제
- 교통 정보: 항공·버스 등 추가, 수정, 삭제
- 체크리스트: 준비 항목 추가, 이름 변경, 삭제

일정 편집 창에서 `식사 일정`을 선택하면 FOOD PLAN에 자동으로 표시됩니다. 지도 링크나 예약 링크는 URL을 입력한 항목에만 버튼이 표시됩니다.

일정과 숙소에는 파일을 첨부할 수 있습니다. 파일 선택으로 올린 파일은 Google Drive의 `solsol-travel-attachments` 폴더에 저장되고, 여행 데이터에 공유 링크가 기록됩니다. 기존처럼 GitHub 파일 경로를 직접 입력하는 방식도 사용할 수 있습니다.

일정 항목의 상태는 아래 세 가지를 사용합니다.

```js
confirmed // 확정
planned   // 계획
tbd       // 미정
```

장소에 `mapUrl`, 식당이나 숙소에 `reservationUrl`을 넣으면 해당 버튼이 자동으로 표시됩니다. 빈 문자열이면 버튼이 표시되지 않습니다.

## 저장되는 개인 메모

체크리스트 항목·체크 상태와 여행 메모도 여행 데이터에 포함되어 Google Drive에 저장됩니다. 공개 GitHub Pages와 링크 공유형 Apps Script를 사용하므로 실명, 전화번호, 예약번호, 카드번호, QR 코드 등의 민감한 개인정보는 입력하지 않는 것을 권장합니다.

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소의 `main` 브랜치에 push합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**를 선택합니다.
4. 브랜치는 `main`, 폴더는 `/root`를 선택하고 저장합니다.

잠시 후 생성된 GitHub Pages 주소에서 PC와 휴대폰으로 일정을 확인할 수 있습니다.
